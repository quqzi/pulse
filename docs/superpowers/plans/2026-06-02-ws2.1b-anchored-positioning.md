# WS2.1b — Anchored Block Popovers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop the two calendar block popovers (edit + create) from clipping off-screen by anchoring them with `@floating-ui/dom` (flip + shift/clamp), on all viewport sizes.

**Architecture:** A thin reusable Svelte action `anchored.ts` wraps `@floating-ui/dom`'s `computePosition` with `offset` + `flip` + `shift` middleware and `autoUpdate`. The CalBlock edit popover anchors to its `.cal-block`; the create `BlockPopover` anchors to the pending-block ghost in WeekGrid. Their static `position/top/left` are removed (the action sets `position: fixed` + computed coords).

**Tech Stack:** SvelteKit 2, TypeScript, `@floating-ui/dom`, Svelte actions.

**Spec:** `docs/superpowers/specs/2026-06-02-ws2.1b-anchored-positioning-design.md`.

**Testing note:** `anchored.ts` is a thin DOM/layout wrapper over `@floating-ui/dom` with no pure logic to extract, so there is no unit test (same situation as the DOM half of `draggable`). It's verified in the browser/emulation at screen edges (Task 4).

```ts
// src/lib/actions/anchored.ts
import { computePosition, offset, flip, shift, autoUpdate, type Placement } from '@floating-ui/dom';

export interface AnchoredOptions {
  /** The element to position against. May be undefined briefly until a bound ref resolves. */
  anchor: HTMLElement | undefined;
  /** Preferred placement (default 'bottom-start'). */
  placement?: Placement;
  /** Gap in px between anchor and floating element (default 6). */
  gutter?: number;
}

/**
 * Positions `node` relative to `options.anchor`, flipping when there's no room
 * and shifting to stay within the viewport with an 8px gutter. Uses a fixed
 * positioning strategy so the popover escapes any clipped/scrolled ancestor.
 */
export function anchored(node: HTMLElement, options: AnchoredOptions) {
  let opts = options;
  let cleanup: () => void = () => {};

  function update() {
    if (!opts.anchor) return;
    computePosition(opts.anchor, node, {
      strategy: 'fixed',
      placement: opts.placement ?? 'bottom-start',
      middleware: [offset(opts.gutter ?? 6), flip(), shift({ padding: 8 })],
    }).then(({ x, y }) => {
      Object.assign(node.style, { position: 'fixed', left: `${x}px`, top: `${y}px` });
    });
  }

  function start() {
    cleanup();
    cleanup = opts.anchor ? autoUpdate(opts.anchor, node, update) : () => {};
  }

  start();

  return {
    update(next: AnchoredOptions) {
      opts = next;
      start();
    },
    destroy() {
      cleanup();
    },
  };
}
```

- [ ] **Step 2: Bind the block element as the anchor**

On the root `.cal-block` element, add `bind:this={blockEl}` (keep all existing attributes/directives):

```svelte
<div
  class="cal-block"
  class:suggested={slot.isAiSuggested}
  class:focus-block={slot.isFocusBlock && !!subject}
  style="background: {blockBg}; border: {blockBorder}; color: {blockColor};"
  bind:this={blockEl}
  on:click={onBlockClick}
```

- [ ] **Step 3: Anchor the popover**

Change the popover's opening tag (currently `<div class="block-popover" on:click|stopPropagation>`) to use the action:

```svelte

    <div class="block-popover" use:anchored={{ anchor: blockEl, placement: 'bottom-start', gutter: 6 }} on:click|stopPropagation>
```

- [ ] **Step 4: Drop the static positioning from `.block-popover` CSS**

In the `<style>` block, the `.block-popover` rule currently begins:

```css
  .block-popover {
    position: absolute;
    top: calc(100% + 6px);
    left: 0;
    z-index: 200;

    ...
  }
```

Remove the `position: absolute;`, `top: calc(100% + 6px);`, and `left: 0;` lines (the action sets `position: fixed` + `left`/`top`). Keep everything else (`z-index`, `background`, `border`, `border-radius`, `padding`, `min-width`, `box-shadow`, `color`). Result:

```css

    z-index: 200;
    background: var(--bg2);
    border: 1px solid var(--border);
    border-radius: var(--radius-md);
    padding: 10px 12px;
    min-width: 200px;
    box-shadow: 0 4px 16px rgba(0,0,0,0.15);
    color: var(--text);
```
