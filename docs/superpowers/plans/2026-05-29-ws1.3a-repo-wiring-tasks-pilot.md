# WS1.3a — Data-layer restructure + Supabase adapter + tasks pilot

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the WS1.2 engine to the real app on one pilot entity (**tasks**) — proving the full pattern (store restructure → Supabase adapter → production wiring → entity repo → call-site cutover) end-to-end — while every other entity keeps running on `db.ts`.

**Architecture:** Break the `data.ts ⇄ repository` circular import by moving the entity writables into a dependency-free `src/lib/data/stores.ts` and `authCtx` into `src/lib/data/authctx.ts`; `stores/data.ts` re-exports both so all existing imports keep working. Add the Supabase adapter and a `repo()` wiring helper that binds the engine to `authCtx` + `toast` + the local/supabase adapters. Migrate the **tasks** entity (one `entities.ts` repo, its `loadData` read, and all 5 task write sites across the tasks page + dashboard). This is the only behavior-changing plan in WS1 so far, so it ends with a **browser verification** step.

**Tech Stack:** Svelte 5 stores, Supabase JS v2, TypeScript, Vitest.

**Source of truth:** spec §4.1, §4.1a, §4.7. **Prerequisite:** WS1.2 merged (engine, local/mock adapters, toast, `id`).

**Greenfield note:** the tasks localStorage key changes from `pulse_tasks` → `pulse.tasks` (spec §4.3). Per the approved greenfield decision, any existing guest task data under the old key is abandoned (acceptable; no migration).

### Task 3: Supabase adapter

**Files:**
- Create: `src/lib/data/adapters/supabase.ts`

> Not unit-tested in Node (it imports `$lib/supabase` → `$env/static/public`, which the Node Vitest config can't resolve). It is exercised via the browser verification in Task 7 and by the real app.

- [ ] **Step 1: Create the adapter**

Create `src/lib/data/adapters/supabase.ts`:
```ts
import { supabase } from '$lib/supabase';
import type { Adapter } from '$lib/data/engine';

export interface SupabaseAdapterConfig<T> {
  table: string;
  userId: string;
  toRow: (item: T) => Record<string, unknown>;
  fromRow: (row: Record<string, unknown>) => T;
  orderColumn?: string;
  ascending?: boolean;
}

export function supabaseAdapter<T extends { id: string }>(cfg: SupabaseAdapterConfig<T>): Adapter<T> {
  return {
    async list() {
      let q = supabase.from(cfg.table).select('*').eq('user_id', cfg.userId);
      if (cfg.orderColumn) q = q.order(cfg.orderColumn, { ascending: cfg.ascending ?? true });
      const { data, error } = await q;
      if (error) throw error; // engine.load() catches -> read-empty-on-error (store unchanged)
      return (data ?? []).map(cfg.fromRow);
    },
    async save(item) {
      const { error } = await supabase.from(cfg.table).upsert(cfg.toRow(item));
      if (error) throw error; // engine.save() catches -> rollback + toast
    },
    async remove(id) {
      const { error } = await supabase.from(cfg.table).delete().eq('id', id);
      if (error) throw error;
    },
  };
}
```

- [ ] **Step 1: Create the wiring helper**

Create `src/lib/data/repository.ts`:
```ts
import { get } from 'svelte/store';
import { createRepository, type RepoConfig, type Repository, type Adapter } from '$lib/data/engine';
import { localAdapter } from '$lib/data/adapters/local';
import { supabaseAdapter } from '$lib/data/adapters/supabase';
import { authCtx } from '$lib/data/authctx';
import { toast } from '$lib/stores/toast';

export interface EntityConfig<T extends { id: string }> extends RepoConfig<T> {
  lsKey: string;
  table: string;
  toRow: (item: T) => Record<string, unknown>;
  fromRow: (row: Record<string, unknown>) => T;
  orderColumn?: string;
  ascending?: boolean;
}

/** Binds the pure engine to real deps: authCtx for mode/userId, toast for errors, local/supabase adapters. */
export function repo<T extends { id: string }>(cfg: EntityConfig<T>): Repository<T> {
  const local = localAdapter<T>(cfg.lsKey);
  const cloud = (userId: string): Adapter<T> =>
    supabaseAdapter<T>({
      table: cfg.table,
      userId,
      toRow: cfg.toRow,
      fromRow: cfg.fromRow,
      orderColumn: cfg.orderColumn,
      ascending: cfg.ascending,
    });

  return createRepository<T>(
    { store: cfg.store, order: cfg.order },
    {
      getMode: () => get(authCtx).mode,
      selectAdapter: (mode) => (mode === 'guest' ? local : cloud(get(authCtx).userId)),
      onError: (m) => toast.error(m),
    },
  );
}
```
