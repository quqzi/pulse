# WS1.3b — Remaining entities + bespoke methods Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the 7 remaining entities (`subjects, topics, srsCards, sessions, templates, scheduleSlots, scores`) off `db.ts` onto the WS1.2 repository engine — including the 9 bespoke methods that don't fit generic `load/save/remove` — so every page reads/writes through `data/` and no page imports `db.ts`.

**Architecture:** The generic engine (optimistic write-through + rollback + read-empty-on-error) stays unchanged. Two small **pure** helpers are added to `engine.ts` — `loadInto` (windowed reads) and `writeThrough` (bespoke writes) — plus a guest-storage util `data/ls.ts`. Each entity exports a repo object = `{ ...repo(genericCfg), ...bespoke methods }` in a single `data/entities.ts`; all mappers live in `data/mappers.ts`. Bespoke writes follow one uniform shape: `writeThrough(store, optimistic, persist, {order, onError})` where the guest persist is `lsWrite(key, get(store))` and the auth persist is a specific Supabase call. Cascade deletes (multi-store) are explicit snapshot/rollback. Migration is **behavior-preserving**: sessions keep today's window (90-day auth / uncapped guest); `removeCascade` keeps today's guest-vs-auth divergence.

**Tech Stack:** Svelte 5 stores, Supabase JS v2, TypeScript, Vitest.

**Source of truth:** roadmap spec `docs/superpowers/specs/2026-05-29-pulse-roadmap-and-foundation-design.md` §4.1, §4.1a, §4.7. **Prerequisite:** WS1.3a merged (engine, local/mock/supabase adapters, `repo()` helper, `tasksRepo`, `data/stores.ts`, `data/authctx.ts`, toast, `$lib/id`).

**Key facts established during design (verified against the live DB on 2026-05-30):**
- **The FK cascades already exist** (`topics.subject_id`, `srs_cards.topic_id` are both `on delete cascade`; subject delete also cascades sessions/schedule/scores; `tasks.subject_id` is `set null`). **No schema migration is needed.**
- **`srs_cards` has no `subject_id` column**, yet `SrsCard.subjectId` exists in the type and `db.saveTopic` writes it. It is **write-only** (review/dashboard/subjects all resolve a card's subject via `topic.subjectId`; `srs.ts` never reads it). Task 2 drops the field — this fixes a latent auth bug and keeps the card mapper matching the real table.

**Greenfield note (spec §4.3):** localStorage keys move to the `pulse.<storeName>` namespace (`pulse.subjects`, `pulse.topics`, `pulse.srsCards`, `pulse.sessions`, `pulse.templates`, `pulse.scheduleSlots`, `pulse.scores`). Any guest data under the old `pulse_*` keys is abandoned (acceptable; no migration). Onboarding's guest subject write must move to `pulse.subjects` (Task 5) or guest onboarding → subjects silently breaks.

**Out of scope (deferred, do NOT do here):** deleting the now-dead `db.ts` and the dead `seedSubjectsFromNames` shim (WS1.3c); the 90→112 `HISTORY_DAYS` parity fix (WS1.4). `db.ts` is left in place, dead-but-compiling, at the end of this plan.

```ts
/** Read into a store with the read-empty-on-error contract (G13). Used by windowed bespoke reads. */
export async function loadInto<T>(
  store: Writable<T[]>,
  fetch: () => Promise<T[]>,
  order?: (a: T, b: T) => number,
): Promise<T[]> {
  try {
    const items = await fetch();
    store.set(order ? [...items].sort(order) : items);
    return items;
  } catch {
    return get(store);
  }
}

/** Optimistic write-through with rollback (G8) for bespoke writes that the generic save/remove don't cover. */
export async function writeThrough<T>(
  store: Writable<T[]>,
  optimistic: (arr: T[]) => T[],
  persist: () => Promise<void>,
  opts: { order?: (a: T, b: T) => number; onError: (message: string) => void; errorMsg?: string },
): Promise<void> {
  const snapshot = get(store);
  const next = optimistic(snapshot);
  store.set(opts.order ? [...next].sort(opts.order) : next);
  try {
    await persist();
  } catch {
    store.set(snapshot);
    opts.onError(opts.errorMsg ?? "Couldn't save — try again");
  }
}
```

```ts
/** Bulk localStorage helpers for the guest path. Mirrors the localAdapter's JSON guard. */
export function lsRead<T>(key: string): T[] {
  if (typeof localStorage === 'undefined') return [];
  try {
    return JSON.parse(localStorage.getItem(key) ?? '[]') as T[];
  } catch {
    return [];
  }
}

export function lsWrite<T>(key: string, items: T[]): void {
  if (typeof localStorage === 'undefined') return;
  localStorage.setItem(key, JSON.stringify(items));
}
```

Replace the inline `read`/`write` closures in `src/lib/data/adapters/local.ts` with the shared util (behavior identical):

```ts
import type { Adapter } from '$lib/data/engine';
import { lsRead, lsWrite } from '$lib/data/ls';

/** localStorage-backed adapter. Stores a JSON array of camelCase entities under `lsKey`. */
export function localAdapter<T extends { id: string }>(lsKey: string): Adapter<T> {
  return {
    async list() {
      return lsRead<T>(lsKey);
    },
    async save(item) {
      const all = lsRead<T>(lsKey);
      const i = all.findIndex((x) => x.id === item.id);
      if (i >= 0) all[i] = item;
      else all.push(item);
      lsWrite(lsKey, all);
    },
    async remove(id) {
      lsWrite(lsKey, lsRead<T>(lsKey).filter((x) => x.id !== id));
    },
  };
}
```

```ts
export const subjectsRepo = {
  ...subjectsBase,
  /**
   * Delete a subject and its dependents. Guest: purge topics + their cards in localStorage.
   * Auth: delete the subject; the DB FK cascade removes topics/cards (and sessions/schedule/scores).
   * Stores refreshed for subjects/topics/srsCards only (sessions/scores resync on next loadData) —
   * matches today's behavior exactly.

  async removeCascade(id: string): Promise<void> {
    const { mode } = getAuthContext();
    const snapSub = get(subjects);
    const snapTop = get(topics);
    const snapCard = get(srsCards);
```

```ts
import { newId } from '$lib/id';
import { defaultCard } from '$lib/srs';

const topicOrder = (a: Topic, b: Topic) => a.orderIndex - b.orderIndex;

const topicsBase = repo<Topic>({
  store: topics,
  lsKey: 'pulse.topics',
  table: 'topics',
  toRow: topicToRow,
  fromRow: topicFromRow,
  orderColumn: 'order_index',
  ascending: true,
  order: topicOrder,
});

export const topicsRepo = {
  load: topicsBase.load,

  /** Topic edit (name/order). Injects user_id (required NOT NULL) from authCtx for the auth UPSERT. */
  async save(topic: Topic): Promise<void> {
    const { userId, mode } = getAuthContext();
    await writeThrough(
      topics,
      (arr) => arr.map(t => (t.id === topic.id ? topic : t)),
      async () => {
        if (mode === 'guest') lsWrite('pulse.topics', get(topics));
        else {
          const { error } = await supabase.from('topics').upsert({ ...topicToRow(topic), user_id: userId });
          if (error) throw error;
        }
      },
      { order: topicOrder, onError: toast.error },
    );
  },

  /** Add a topic and ensure exactly one SRS card for it. Returns the card. Idempotent on the card. */
  async create(topic: Topic): Promise<SrsCard> {
    const { userId, mode } = getAuthContext();
    const existing = get(srsCards).find(c => c.topicId === topic.id);
    const card: SrsCard = existing ?? { id: newId(), topicId: topic.id, userId, ...defaultCard() };

    const snapTop = get(topics);
    const snapCard = get(srsCards);
    topics.set([...snapTop.filter(t => t.id !== topic.id), topic].sort(topicOrder));
    if (!existing) srsCards.set([...snapCard, card]);

    try {
      if (mode === 'guest') {
        lsWrite('pulse.topics', get(topics));
        if (!existing) lsWrite('pulse.srsCards', get(srsCards));
      } else {
        const { error: te } = await supabase.from('topics').upsert({ ...topicToRow(topic), user_id: userId });
        if (te) throw te;
        if (!existing) {
          const { error: ce } = await supabase.from('srs_cards').upsert(cardToRow(card));
          if (ce) throw ce;
        }
      }
    } catch {
      topics.set(snapTop);
      srsCards.set(snapCard);
      toast.error("Couldn't save — try again");
    }
    return card;
  },

  /** Delete a topic and its card. Guest purges localStorage; auth relies on the srs_cards FK cascade. */
  async removeCascade(id: string): Promise<void> {
    const { mode } = getAuthContext();
    const snapTop = get(topics);
    const snapCard = get(srsCards);
    topics.set(snapTop.filter(t => t.id !== id));
    srsCards.set(snapCard.filter(c => c.topicId !== id));
    try {
      if (mode === 'guest') {
        lsWrite('pulse.topics', get(topics));
        lsWrite('pulse.srsCards', get(srsCards));
      } else {
        const { error } = await supabase.from('topics').delete().eq('id', id);
        if (error) throw error;
      }
    } catch {
      topics.set(snapTop);
      srsCards.set(snapCard);
      toast.error("Couldn't delete — try again");
    }
  },
};

  store: srsCards,
  lsKey: 'pulse.srsCards',
  table: 'srs_cards',
  toRow: cardToRow,
  fromRow: cardFromRow,
});

export const srsRepo = {

  /** Update-only (never inserts); sets updated_at. SM-2 writes go here, not generic save. */

      srsCards,

        else {

            ease: card.ease,
            interval_days: card.intervalDays,
            due_date: card.dueDate,
            reps: card.reps,
            updated_at: new Date().toISOString(),
          }).eq('id', card.id);
          if (error) throw error;
        }
      },
      { onError: toast.error },
    );
  },
};
```

```ts
  store: sessions,
  lsKey: 'pulse.sessions',

  toRow: sessionToRow,
  fromRow: sessionFromRow,
  orderColumn: 'started_at',

  async load(): Promise<StudySession[]> {

        .order('started_at', { ascending: false });
```

```ts
import type { ScheduleSlot } from '$lib/types';
import { scheduleSlots } from '$lib/data/stores';
import { slotFromRow, slotToRow } from '$lib/data/mappers';

const slotOrder = (a: ScheduleSlot, b: ScheduleSlot) => a.startTime.localeCompare(b.startTime);

const scheduleBase = repo<ScheduleSlot>({
  store: scheduleSlots,
  lsKey: 'pulse.scheduleSlots',
  table: 'schedule_slots',
  toRow: slotToRow,
  fromRow: slotFromRow,
  order: slotOrder,
});

export const scheduleRepo = {
  save: scheduleBase.save,
  remove: scheduleBase.remove,

  /** Windowed read for the viewed week. Lives outside loadData (called reactively per week). */
  async loadWeek(weekStart: string, weekEnd: string): Promise<ScheduleSlot[]> {
    const { userId, mode } = getAuthContext();
    return loadInto(scheduleSlots, async () => {
      if (mode === 'guest') {
        return lsRead<ScheduleSlot>('pulse.scheduleSlots').filter(s => s.startTime >= weekStart && s.startTime < weekEnd);
      }
      const { data, error } = await supabase.from('schedule_slots').select('*')
        .eq('user_id', userId)
        .gte('start_time', weekStart)
        .lt('start_time', weekEnd)
        .order('start_time');
      if (error) throw error;
      return (data ?? []).map(slotFromRow);
    }, slotOrder);
  },

  /** Bulk confirm: flip isConfirmed=true / isAiSuggested=false for the given slots, persist all, one store update. */
  async confirmAll(slots: ScheduleSlot[]): Promise<void> {
    const { mode } = getAuthContext();
    const ids = new Set(slots.map(s => s.id));
    await writeThrough(
      scheduleSlots,
      (arr) => arr.map(s => (ids.has(s.id) ? { ...s, isConfirmed: true, isAiSuggested: false } : s)),
      async () => {
        if (mode === 'guest') {
          // The store holds only the viewed week, but the localStorage key holds ALL weeks —
          // read the full set, transform by id, write the full set back (never lsWrite(get(store)) here).
          const all = lsRead<ScheduleSlot>('pulse.scheduleSlots')
            .map(s => (ids.has(s.id) ? { ...s, isConfirmed: true, isAiSuggested: false } : s));
          lsWrite('pulse.scheduleSlots', all);
        } else {
          const rows = slots.map(s => slotToRow({ ...s, isConfirmed: true, isAiSuggested: false }));
          const { error } = await supabase.from('schedule_slots').upsert(rows);
          if (error) throw error;
        }
      },
      { order: slotOrder, onError: toast.error },
    );
  },
};
```
