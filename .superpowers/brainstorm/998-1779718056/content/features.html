Calendar feature set

Core features are always included. Pick any extras you want.

Core — always included

✓
Week grid — 7-day × hourly grid, subject-colored blocks, current time indicator
✓
Drag to create blocks — drag on empty slot → popover to pick subject + topic
✓
Drag to move & resize — drag block to reschedule, drag bottom edge to change duration
✓
AI auto-schedule — generates ghosted suggestions based on SRS due dates, analytics weak spots, tasks with deadlines. Accept all or one-by-one.
✓
Tasks on calendar — tasks with due dates appear as pills at the top of their due day (like Google Calendar all-day events)

Extras — select what you want

+

Daily load bar

Colored progress bar above each day column — planned hours vs. daily goal. Green = on track, amber = over limit. Lets you spot overloaded days at a glance.

+

Quick-start timer from block

Tap a block → small popover with "Start session" button. Launches the timer pre-filled with subject + topic. Logs back to the same block when done.

+

Retroactive session logging

Click a past empty time slot → log a session that already happened. Feeds study hours into Analytics without needing the timer. Good for study sessions away from the device.

+

Recurring blocks

When creating a block, optionally set it to repeat — daily, weekdays, or specific days (Mon / Wed / Fri). Recurring blocks propagate forward and can be edited individually or all at once.

+

Overload warning

Subtle red tint on the day load bar when planned hours exceed your daily goal. Also warns if the same subject is scheduled 3+ days in a row without a break.

+

Subject filter chips

Row of subject chips above the grid. Tap to hide/show specific subjects. Useful for focusing on one subject's schedule or hiding completed subjects from view.

+

Exam countdown banner

Small persistent strip at the top of the calendar: "TCAS in 47 days". Pulses amber when <14 days out. Links to the exam date set in onboarding.

+

Weekly summary sidebar

Collapsible right sidebar showing: planned vs. actual hours this week, SRS cards due count, and which subject is most behind based on analytics. Collapses to an icon on mobile.
